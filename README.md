# Ignite Coffee Co.

Premium mock-up for **Ignite Coffee Co.** in Fort St. James, BC — marketing site + order-ahead PWA.

## Demo surfaces

| Route | What it is |
|---|---|
| `/` | Marketing website (hero, menu boards, Facebook feed, Google reviews, visit) |
| `/app` | Ordering web app / PWA (cart, pickup, mock checkout, stamps, favourites) |
| `/brand` | Brand guide |

Payments are **mock only** — no real card processing.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm test
npm run build
```

## Stack

Next.js (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Zustand · Motion · Serwist (PWA)

## Note

Design concept — not the official Ignite site. Built as a pitch / demo for the shop owners.
